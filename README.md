#  Introduction

This Calculator application is a desktop GUI program developed with **Tkinter**, Python's standard graphical user interface library. It allows users to perform basic arithmetic calculations through an interactive interface using buttons instead of typing commands in the terminal.

The project demonstrates event-driven programming, widget management, and function handling in Python.

*  Addition

#  How It Works

### 1. Number Input

Click the number buttons to enter digits into the calculator display.

### 2. Select an Operation

Choose one of the supported operations:

* Addition (+)
* Subtraction (-)
* Multiplication (*)
* Division (/)

The calculator stores the first number and waits for the second input.

### 3. Calculate

Press the **=** button to perform the selected operation and display the result.

### 4. Clear

Press the **Clear** button to remove all input from the display.

---

# Usage

1. Launch the application.
2. Enter the first number.
3. Click an arithmetic operator.
4. Enter the second number.
5. Press **=** to view the result.
6. Use **Clear** to reset the calculator.
